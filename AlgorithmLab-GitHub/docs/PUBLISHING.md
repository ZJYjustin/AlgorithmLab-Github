# 上传到自己的 GitHub

本目录已经按源码仓库整理。上传 ZIP 文件本身只会把它当作一个下载文件；要让 GitHub 展示源码，请先解压。

## 在网页上传

1. 建议在自己的 GitHub 账号下新建独立仓库，例如 `algorithm-lab-local`，先创建空仓库。
2. 解压上传包，进入里面的 `AlgorithmLab-GitHub` 目录。
3. 选择 Add file → Upload files，将该目录内部的文件和文件夹上传到仓库根目录；包含 `.github` 和 `.gitignore`。
4. 根目录应直接看到 `README.md`、`LICENSE`、`lab.py` 和 `examples/`，而不是再套一层 ZIP。
5. 填写提交说明并提交；检查 README 能显示、LICENSE 存在、测试工作流能运行。

若放入已有仓库，请使用独立子目录并保留该目录的 LICENSE 和来源说明，不覆盖已有 README 或其他项目内容。

## 公开包和原本地包不要混用

只上传这个公开整理包，不要把旧的 AlgorithmLab 整个目录拖上去。旧版可能包含授权未确认的第三方库、个人路径、生成报告、IDE 状态或缓存。
`.gitignore` 是 Git 的忽略规则，不能替你阻止网页手动上传；本次源码 ZIP 已在打包时排除了这些生成目录。

## 署名和发布范围

可以在 README 加上自己的 GitHub 名字、学习经历、修改说明和演示。现有版权行使用 Algorithm Lab contributors；确认实际贡献者署名后可以补充自己的姓名或账号。
保留设计致谢、AI 辅助开发说明和 THIRD_PARTY.md，不应宣称这是上游官方产品。
MIT 是本次准备的许可选择，保留许可文本才能让其他人按相应条件使用你的公开项目。

本次只生成文件，没有创建远程仓库、推送代码或向插件市场发布。后续若把自己构建的插件作为 Release 附件，请确认它来自 0.2.0 源码，并在本机 IDE 中验证加载。
